User Notifications by Email and Odoo

Adds a user notification preference that delivers notifications through both email and the Odoo inbox.

Overview

This module extends Odoo Mail notification preferences with an additional option for users who need both email delivery and inbox notifications. When a recipient uses this preference, the notification flow is split into separate inbox and email notifications.

Key Features

Email and inbox preference

Adds an extra user notification type for combined email and Odoo inbox handling.

Inbox notification delivery

Sends matching notifications through Odoo's inbox notification flow.

Email notification delivery

Sends matching notifications through Odoo's email notification flow.

User preference alignment

Keeps the inbox notification group aligned for users using either inbox or combined email and inbox notifications.

How It Works

  1. Install the module.
  2. Select the combined email and inbox notification preference on an internal user.
  3. When Odoo prepares notifications for that user, the module creates inbox delivery data and email delivery data.
  4. Odoo then sends the notification through both supported channels.

Benefits

  • Supports users who want email notifications without losing Odoo inbox visibility.
  • Uses Odoo's existing mail notification mechanisms.
  • Adds the behavior without adding new menus or configuration screens.
